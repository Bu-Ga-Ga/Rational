# Программа для работы с рациональными числами (дробями)

## Описание программы

Программа реализует классы для работы с массивами рациональных чисел (дробей) с возможностью выполнения арифметических операций и ввода/вывода данных.

### Основные классы

1. **Базовый класс `CRat`**:
   - Хранит массивы числителей и знаменателей
   - Реализует основные арифметические операции:
     - Сложение (`+`)
     - Вычитание (`-`)
     - Скалярное произведение (`*`)
   - Содержит метод сокращения дробей (`reduction`)
   - Обеспечивает базовый функционал ввода/вывода

2. **Производные классы**:
   - `CRat1` - реализует вывод дробей в формате `(a/b)` в строку
   - `CRat2` - реализует вывод дробей в формате `{a/b}` в столбец

## Функциональность

### Основные операции
- Сложение и вычитание массивов дробей
- Скалярное произведение массивов дробей
- Автоматическое сокращение дробей
- Чтение данных из файла
- Запись результатов в файлы в разных форматах
